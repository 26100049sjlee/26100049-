# 🎓 스마트 학점 계산기 (Smart GPA Calculator)

생성형 AI와 협업하여 파이썬(Python)으로 시작해 웹 애플리케이션으로 발전시킨 **생활 밀착형 학점 계산 및 성적 관리 프로그램**입니다.

## 🌐 웹사이트 바로가기
👉 [스마트 학점 계산기 실행하기](https://chanyeong-dev.github.io/GPA-Calculator/)

## 📌 프로젝트 소개
대학생이 수강한 과목명, 학점, 성적(A+ ~ F)을 입력하면 4.5 만점 기준으로 총 이수 학점과 평균 평점(GPA)을 실시간으로 계산해 주는 웹 프로그램입니다.

## ✨ 주요 기능
* **과목 및 성적 등록**: 과목명, 학점(1~6학점), 성적(드롭다운 선택)을 간편하게 입력
* **입력 오류 방지**: 드롭다운 메뉴를 통해 정해진 성적 외 오타 입력을 사전에 차단
* **실시간 GPA 계산**: 과목을 추가하거나 삭제할 때마다 총 이수 학점과 평균 학점을 즉시 재계산
* **과목 삭제 관리**: 잘못 입력한 과목을 버튼 클릭 한 번으로 목록에서 제거

## 📖 사용 방법
1. 상단 입력창에 **과목명**과 **학점**을 입력합니다.
2. 드롭다운에서 해당 과목의 **성적(A+ ~ F)**을 선택합니다.
3. **[추가]** 버튼을 누르면 아래 표에 과목이 등록되고 하단에 평균 학점이 자동으로 계산됩니다.
4. 수정이 필요하면 해당 과목 우측의 **[삭제]** 버튼을 눌러 지울 수 있습니다.
